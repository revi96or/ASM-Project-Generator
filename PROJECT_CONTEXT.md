# PROJECT_CONTEXT.md

**Описание:** Актуальный контекст ASM Project Generator для продолжения работы в новых сессиях.  
**Версия:** 2.3.0  
**Автор:** Новожилов Артем

## Проект

Windows-приложение для генерации файлов проекта трафаретного принтера ASM на базе:

- `template.PR1`
- `template.ISD`
- `template.pxf`

## Текущее состояние

Это HTML/CSS/JavaScript приложение на Electron.

Сборка работает как Electron-приложение с HTML/CSS/JS интерфейсом.

Умеет:

- читать рабочую папку с шаблонами и `pr1_known_map.json`;
- подставлять стартовые значения из `template.PR1`;
- сохранять JSON-снимок проекта в локальную папку и дублировать в `%AppData%`;
- генерировать `PR1`, `ISD`, `pxf`;
- менять содержимое `PR1` по полям формы;
- писать AOI `.txt`;
- показывать статусы принтера и готовности сохранения;
- работать с раздельным скроллом левой и правой части;
- показывать и скрывать подсказки через кнопку **Настройки**.
- проверять обновления из GitHub Releases;
- хранить пути, подсказки, автообновление и служебные данные пользователя отдельно от папки программы.

## Логика формы

### Неизменная логика

Поля, которые не очищаются при фокусе:

- Название платы
- Комментарий
- Смещение остановки по X
- Точка стопора Y
- Center Board Minus
- Center Board 3
- Center Board

### Динамическая логика

Остальные редактируемые поля очищаются при фокусе.
Если пользователь не ввёл новое значение — возвращается последнее введённое значение, а не заводской дефолт.

### Комментарий

- ID: `0x2710`
- автопрефикс строится как `270 + Board Y / 2`
- длина ограничена `32` символами

### Размеры платы

- `0x000B` — длина платы X
- `0x000A` — высота платы Y
- `0x000C` — толщина платы

### Реперные знаки

- `0x0032` — количество реперных знаков
- `0x0033` — `REF1_X`
- `0x0034` — `REF1_Y`
- `0x0035` — `REF2_X`
- `0x0036` — `REF2_Y`
- `0x0037` — `REF3_X`
- `0x0038` — `REF3_Y`

### Позиционирование платы

- `0x7613` — режим остановки платы
- `0x765D` — сторона платы
- `0x0046` — смещение остановки по X
- `0x0047` — Stop Board Y

### Печать

- `0x0010` — давление переднего ракеля
- `0x0011` — давление заднего ракеля
- `0x0015` — количество проходов ракеля
- `0x01C8` — скорость печати переднего ракеля
- `0x01C7` — скорость печати заднего ракеля
- направление печати — swap-группа, `Backward = группа A`, `Forward = группа B`

### Разделение

- `0x0013` — скорость разделения
- `0x2715` — расстояние разделения

### Паста и обслуживание

- `0x0023` — количество перемешиваний
- `0x0028` — частота очистки
- `0x766C` — давление перемешивания
- `0x766D` — скорость перемешивания
