# Если снёс Windows / поменял материнку — как всё вернуть

Этот файл написан специально для тебя, чтобы ничего не держать в голове.
Прочитай целиком один раз, прежде чем что-то переустанавливать.

## Главное: код программы уже в безопасности

Весь код программы (`SMT Pro Gen`) хранится на GitHub, в облаке, а не только на твоём
компьютере:

**https://github.com/revi96or/ASM-Project-Generator**

Переустановка Windows, смена платы/процессора, даже полная замена диска — **никак не
повлияют на код**. Он никуда не денется. Единственное, что можно потерять — это то, что
физически лежит ТОЛЬКО на твоём диске и не было загружено на GitHub (см. раздел ниже).

## Шаг 0. Сделай это ДО переустановки (если ещё не поздно)

Скопируй эти две папки на флешку, внешний диск или в облако (Яндекс.Диск, Google Drive и
т.п.) — они не хранятся на GitHub:

1. `C:\settings\Pick Place\Dev\PickAndPlaceAddin4.xlam` — рабочий файл с макросами станка.
2. `C:\TEST\pnp_test_harness\` — папка с тестовыми скриптами (не критично, но пригодится).

Если переустановка уже случилась и эти файлы были только на системном диске без
бэкапа — их, к сожалению, не вернуть. Код программы при этом всё равно цел (он в GitHub).

## Вариант А — тебе нужна только САМА ПРОГРАММА (не правки кода)

Если ты просто хочешь продолжить пользоваться SMT Pro Gen на новом/переустановленном
компьютере — разработка тебе не нужна, достаточно:

1. Открыть в браузере: **https://github.com/revi96or/ASM-Project-Generator/releases/latest**
2. Скачать файл `SMT_Pro_Gen-<версия>-setup.exe`.
3. Запустить и установить, как обычную программу.
4. Готово — дальше программа сама проверяет обновления через кнопку "Проверить обновления".

Файлы `Help.pdf` и `Compare TXT` уже входят в установщик — отдельно их копировать не нужно.

## Вариант Б — нужно продолжать разработку/правки вместе с ИИ

Если тебе нужно вносить изменения в код (как мы делали раньше):

### Что поставить на новый Windows

1. **Git for Windows** — https://git-scm.com/download/win
2. **Node.js** (версия 24 или новее, можно LTS) — https://nodejs.org
3. **GitHub CLI** (`gh`) — нужен, если будешь публиковать релизы сам — https://cli.github.com
4. Приложение Copilot/GitHub Copilot CLI — то, через которое мы с тобой общаемся — ставится
   отдельно, не часть этого репозитория.

### Как скачать код обратно

Открой PowerShell и выполни по порядку:

```powershell
git clone https://github.com/revi96or/ASM-Project-Generator.git
cd ASM-Project-Generator
git checkout notorigami77-carnival-transfer
npm install
npm run build:ui-assets
npm start
```

**Важно:** ветка называется `notorigami77-carnival-transfer`, а не `main` — именно в ней
вся актуальная работа. Если просто сделать `git clone` без `git checkout`, попадёшь в
старую, неактуальную версию.

Если `npm start` запустил окно программы — всё восстановлено.

### Как вернуть внешние файлы

Скопируй обратно из бэкапа (см. Шаг 0):

- `PickAndPlaceAddin4.xlam` → обратно в `C:\settings\Pick Place\Dev\`
- `pnp_test_harness` → обратно в `C:\TEST\`

## Как продолжить работу со мной (ИИ) после восстановления

1. Открой новую сессию/чат в приложении Copilot на этом же репозитории (или укажи путь
   к восстановленной папке).
2. Напиши что-то вроде: *"Прочитай PROJECT_CONTEXT.md, PROJECT_RULES.md и CHANGELOG.md —
   это наш проект, продолжаем работу."*
3. Я прочитаю эти файлы и восстановлю понимание проекта, даже если вся прошлая переписка
   окажется недоступна.

Переписка (сама история чата) может не сохраниться при смене компьютера — но весь важный
контекст о проекте специально продублирован в файлах `PROJECT_CONTEXT.md`,
`PROJECT_RULES.md` и `CHANGELOG.md` внутри репозитория именно на такой случай.
